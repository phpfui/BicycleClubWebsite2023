 ## Version 1.38 (2026-08-26)

 ### New Features
 - Publically viewable folders. All items in a publicly viewable folder can be accessed by anyone with the URL to the folder. Defaults to members only.
 - You can copy [Store Items](/Store/Inventory/manage) easily including options and photos.
 - Content is now available in the [Store](/Store/shop).
 - If a rider signs up and is confirmed for a waitlisted ride, they can not sign up for another ride that day.
 - The system should work better with various character sets and encodings from Microsoft products.

 ### Bug Fixes
 - [My Volunteer Points](/Volunteer/myPoints) better reports ride status reasons.
